# public.app_user

## Description

利用者。設計書の `USER`。`user` はPostgreSQLの予約語のため物理名を変えている（24.2.4）。  
物理削除はせず `disabled_at` で無効化する（20.11）。AUDIT_LOG等から参照されるため。
