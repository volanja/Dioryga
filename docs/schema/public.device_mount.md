# public.device_mount

## Description

機器の搭載位置 — 履歴テーブル（12.2、13.2）。  
**1行で `container_id` と `host_device_id` のどちらか一方だけが埋まる。**  
この排他はDB制約にせず、アプリケーション層で検証する。
