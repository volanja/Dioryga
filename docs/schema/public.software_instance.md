# public.software_instance

## Description

ソフトウェアの固有のインストール単位（9.3）。**バージョンアップを跨いで引き継がれる固有情報**を持つ。  
**`status` を持たない**（9.4.1）。インストール状態は SOFTWARE_INSTALLATION から導出する。
