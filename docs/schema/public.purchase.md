# public.purchase

## Description

購入の記録（10章）。**品目ごとに1行。発注を表すテーブルは持たない**——  
発注番号は重複してよく、注文単位の合計は order_number で寄せて求める。  
数量と通貨も持たない（数えるのは実体、金額は PROJECT.currency）。
