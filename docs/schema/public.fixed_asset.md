# public.fixed_asset

## Description

固定資産（10章）。**`disposal_date` と簿価を持たない**——廃棄は  
DEVICE_ASSIGNMENT の Disposed 行から、簿価は取得価額と経過期間から計算する  
（旧B-1）。持つと二重管理になり必ずずれる。
