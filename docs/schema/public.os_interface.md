# public.os_interface

## Description

OSから見えるインターフェース — 履歴テーブル（8.3、8.5）。  
**物理ポートではなくこちらを中心に置く。**ボンド・VLANサブインターフェース・SVI・  
VMの仮想NICは物理ポートに1対1で対応しない。
