# public.interface_stack

## Description

インターフェースの積み重ね — 履歴テーブル（8.5）。  
**ボンド（1 upper : N lower）とVLANサブインターフェース（1 lower : N upper）の双方を  
扱うため中間テーブルにしている。**向きが逆なので片方向の外部キーでは表せない。
